## About me

I build tools that make data easier to explore, explain, and act on. My work spans fraud detection, machine learning, and interactive web apps. I like taking an idea from a rough script to something people can actually use.

I'm currently pursuing an M.S. in Data Science at the CUNY Graduate Center in New York.

Previously at Definity Insurance, I built fraud intelligence systems, data pipelines, and applied AI solutions, including document tampering detection and tools for investigating linked entities.

Outside work, I experiment with local language models, music tools, and interactive ways to explain machine learning. Some of those experiments live in private repos while I work out what is worth sharing. 

Languages: I speak some French (B1) and Spanish (A2) and am working toward fluency in both.
